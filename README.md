# Strive

Трекер задач с напоминаниями (HTML + CSS + JavaScript, без библиотек).

## Файлы
- index.html - разметка
- style.css - стили (светлая и тёмная тема)
- app.js - вся логика: задачи, localStorage, напоминания
- manifest.json, sw.js, icon.svg - PWA (установка на телефон/ПК, работа офлайн)

## Запуск
Service worker работает только через http://, поэтому запускай через локальный сервер:

    cd strive
    python -m http.server 8000

и открой http://localhost:8000

## Установка на телефон
Выложи папку на GitHub Pages или Netlify, открой ссылку на телефоне
и выбери "Добавить на главный экран".

## Идеи для доработки
- категории/предметы
- статистика и серии дней (streak)
- синхронизация между устройствами (Firebase / Supabase)
- push-уведомления при закрытом приложении

## Supabase (вход и синхронизация)
1. supabase.com -> New project.
2. SQL Editor -> вставь содержимое supabase.sql -> Run.
3. Project Settings -> API: скопируй Project URL и anon public key в config.js.
4. Authentication -> Providers -> Email: для теста выключи "Confirm email".
5. Authentication -> URL Configuration: Site URL = адрес твоего GitHub Pages.
Ключ anon публичный, его можно хранить в коде: данные защищены правилами RLS из supabase.sql.

## Приложение для Windows (.exe)
Проект упакован через Electron.

Локальный запуск: `npm install`, затем `npm start`.
Сборка у себя: `npm run dist` (файлы появятся в папке dist).

Сборка на GitHub: во вкладке Actions запусти "Build Windows exe" (Run workflow),
готовые файлы будут в Artifacts. Для публичного релиза создай тег:

    git tag v1.0.0
    git push origin v1.0.0

Установщик Strive-Setup и портативный Strive-Portable появятся в разделе Releases.

## Что нового (v1.1)
- Громкое напоминание с мелодией, окно выезжает наверх и мигает в панели задач.
- В назначенное время приложение спрашивает «Сделано / Не сделано» (для задач и привычек).
- Финансы: сначала указываешь доход за месяц, потом каждый день пишешь траты одной строкой: «еда 200, игротека 300».

## Что нового (v1.2)
- Закрытие крестиком сворачивает Strive в трей (значок у часов), напоминания продолжают приходить. Полный выход через меню значка.
- В меню значка можно включить запуск вместе с Windows (лучше работает с установщиком, а не с Portable).
- Экзамены: тип (экзамен, зачёт, проект, реферат, курсовая), оценка, раздел «История и оценки» со средним баллом.
